<Aside type="caution" title="Foundation stage">
This is the v0.1 foundation: the server, the SPA shell, and the release rails stand, and the architecture is recorded. The universe itself — the imports, the similarity graph, the sky layout — is what the next releases build. Nothing here is deployed yet.
</Aside>

## What lyrid is

<CardGrid stagger>
	<Card title="One sky, shared" icon="star">
		The layout is canonical: the same star sits in the same place for everyone, so a coordinate is a place you can name, link, and return to. Only the fog over it is yours.
	</Card>
	<Card title="Listening is the fuel" icon="approve-check">
		A preview is a scan, a full listen is a landing, and your ListenBrainz scrobbles are what light the map. Progress cannot be bought or clicked — only heard.
	</Card>
	<Card title="Two modes, chosen once" icon="setting">
		Exploration adds fog, a ship, fuel and quests. Creative opens the whole sky from the first minute, as a daily instrument for studying music. Both stay supported forever.
	</Card>
	<Card title="Built from open data" icon="open-book">
		No rate-limited API sits in the critical path. The universe is assembled locally from full dumps, so its growth is bounded by our own pipeline runs and nobody else's quota.
	</Card>
</CardGrid>
